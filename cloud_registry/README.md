# ☁️ Akili Cloud Registry

Ported from Akili. This module turns the curriculum into what a student device downloads: vectorised course files, system prompts, and a manifest describing both. It is the source of truth for every device.

No LLM is involved on this side: courses are embedded locally, with the same ONNX model the device uses. Nemotron (Nebius Token Factory) is only called on the device, at question time.

---

## 🏗️ Structure

- **`config/curriculum.yaml`**: the master list of classes and subjects to process.
- **`config/settings.py`**: publishing settings (`GCS_BUCKET_NAME`, `GOOGLE_APPLICATION_CREDENTIALS`). No embedding model here, on purpose.
- **`courses/`**: source Markdown organised by grade and subject (`index.md` files are skipped), plus the system prompts in `courses/prompts/*.txt`.
- **`pipeline/`**
  - `batch_pipeline.py`: the main entry point. Reads the Markdown, embeds it, writes Parquet, exports prompts, generates the manifest, and optionally uploads everything to GCS.
  - `manifest_generator.py`: regenerates `manifest.json` alone. **Writes no embedding stamp**, see below.
  - `prompt_exporter.py`: exports the prompts alone, **to a path nothing reads**, see below.
- **`registry/`**: build output. Generated by the pipeline and **not tracked in git**: the distribution channel is the bucket.

The device side lives in `apu/sync/sync_manager.py` and is driven from the dashboard sidebar.

---

## ⚠️ The embedding model is shared with the device

The pipeline and the student device **must embed with the same model**. Query vectors and document vectors are only comparable inside one vector space; a mismatch does not raise an error, it returns noise ranked as though it were relevant.

Both sides therefore read **`apu/config.py`** (`LOCAL_EMBEDDING_MODEL`, `LOCAL_EMBEDDING_DIM`). Never declare a model id in this folder: that is how Akili's registry was once published at 3072 dimensions while devices queried at 384.

The manifest carries the stamp, and a device refuses to download a course from a registry built with another model:

```json
"embedding": {
  "model": "sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2",
  "dim": 384
}
```

**Changing the model means republishing the whole registry**, and every device re-fetching its courses.

## 🛠️ Usage

All commands run from the repository root.

### 1. Configure the curriculum

Edit `config/curriculum.yaml` to define grades and subjects, and put one Markdown file per chapter in `courses/<grade>/<subject>/`.

### 2. Build the registry locally

```bash
uv run python cloud_registry/pipeline/batch_pipeline.py
```

The first run downloads the ONNX embedding model (~240 MB) into `LOCAL_EMBEDDING_CACHE_DIR`, since the pipeline runs on a connected machine. Output goes to `cloud_registry/registry/`: inspect it before anything reaches a device.

The pipeline stops if the embedder produces a width other than `LOCAL_EMBEDDING_DIM`, rather than shipping a registry no device can search.

### 3. Publish to Google Cloud Storage

Set `GCS_BUCKET_NAME` in `.env`, authenticate (service account through `GOOGLE_APPLICATION_CREDENTIALS`, or Application Default Credentials with `gcloud auth application-default login`), then:

```bash
uv run python cloud_registry/pipeline/batch_pipeline.py --upload
```

Devices find the registry through `REGISTRY_MANIFEST_URL` (default `https://storage.googleapis.com/akili-registry/manifest.json`); the bucket name is read from that URL.

### 4. Regenerate the manifest only

```bash
uv run python cloud_registry/pipeline/manifest_generator.py my-bucket-name
```

## Known issues carried over from Akili

Ported as they were, and pinned by tests where it matters:

- **Devices need GCS credentials to download**, not only network access: the client reads through an authenticated storage client.
- **`url` fields in the manifest point to `/courses/<file>`**, while the upload and the download both use the bucket root. The client never reads `url`.
- **`manifest_generator.py` writes no `embedding` stamp**, so devices fall back to the dimension check only.
- **`prompt_exporter.py` writes `registry/prompts.json`**, but the manifest and the device use `registry/prompts/prompts_v1.json`.
- **"Check for Updates" refreshes the system prompts only**, never the courses.
